RAMDISK_ENABLEfalse Enables the RAM disk (sw/cpm-neo/ only). When false, the RAM disk's SRAM array is left out of the design entirely, its address window reads 0 and acks the same cycle like any other unmapped region, and tinymcu_imem.vhd's fetch arbiter never routes fetches there either.
RAMDISK_ADDR_WIDTH15 RAM disk address width in bits. Only meaningful when RAMDISK_ENABLE is true.
XIP_ENABLEfalse Enables the XIP SPI flash controller (tinymcu_imem_xip.vhd). When false, it's left out of the design entirely, its register window reads 0 and acks the same cycle like any other unmapped region, and the fetch arbiter never routes fetches to it either. When true, software can configure and enable it to fetch code from an external SPI flash.
TRACE_ENABLEfalse Simulation only: prints PC=0x... INSTR=0x... <mnemonic> every cycle an instruction is in EX. Default off so testbenches that don't want the noise are unaffected.
